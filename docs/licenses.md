# 第三方许可

分发前应将下列项目的完整许可文本一并放入安装包：

- Slint — Royalty-free License；应用关于页及文档需保留 “Made with Slint” 署名。
- OAR-OCR / RapidOCR 模型 — Apache-2.0。
- dxgi-capture-rs — MIT。
- ONNX Runtime — MIT。
- Source Han Sans（如随包分发）— SIL Open Font License 1.1。
- Rust crates — 以 `Cargo.lock` 对应版本的许可为准。

系统字体（如 Microsoft YaHei）仅在本机运行时调用，不随安装包再分发。
